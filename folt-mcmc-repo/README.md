# FolT-MCMC

Reproducibility materials for the paper

**Folded Transport MCMC: Eliminating Label Switching by Sampling on a Fundamental Domain**

This repository provides code to reproduce the experiments in the paper. It
contains the target-distribution definitions, the folded sampler, the
convergence-diagnostic computation, and scripts that regenerate the synthetic
benchmarks reported in the paper.

## Status

This repository accompanies a manuscript currently under review. The code is
released to support reproducibility. A tagged release will be created upon
acceptance.

## Installation

```bash
git clone https://github.com/<USER>/folt-mcmc.git
cd folt-mcmc
pip install -r requirements.txt
```

Requires Python 3.10+ and PyTorch.

## Reproducing the synthetic experiments

```bash
# regenerate synthetic targets
python scripts/make_synthetic_data.py

# run the Gaussian-mixture dimension-scaling experiment
python experiments/run_gmm.py --config experiments/config.yaml

# run the label-switching experiment
python experiments/run_labelswitch.py --config experiments/config.yaml

# run the Bayesian three-component mixture benchmark
python experiments/run_bayes_mixture.py --config experiments/config.yaml
```

Each script prints the folded and unfolded convergence diagnostic (QC γ) and
writes results to `results/`.

## Data

The synthetic target distributions are fully specified in the paper (Appendix A)
and are regenerated by `scripts/make_synthetic_data.py`. The real-data example
in the paper uses third-party accelerometer measurements that are subject to
confidentiality restrictions and are **not** included in this repository. See
[`DATA.md`](DATA.md) for details.
